# Випуск KAI в Google Play

## 1. Збірка (потрібен Android Studio Ladybug+ або новіший, JDK 17+)

1. Відкрийте папку проєкту в Android Studio → дочекайтесь Gradle Sync.
   Якщо студія запропонує оновити Android Gradle Plugin — погодьтесь (Upgrade Assistant).
2. Перевірте на реальному телефоні: `Run ▶` → у налаштуваннях системи зробіть KAI головним екраном.
3. Запустіть перевірки: `./gradlew lint` (звіт: `app/build/reports/lint-results-debug.html`).

## 2. Ключ підпису (один раз)

```
keytool -genkeypair -v -keystore kai-upload.jks -alias kai-upload \
        -keyalg RSA -keysize 2048 -validity 10000
```

Скопіюйте `keystore.properties.example` → `keystore.properties`, впишіть шлях і паролі.
**Збережіть `kai-upload.jks` і паролі у двох безпечних місцях** (файли в `.gitignore`, у git їх не класти).
У Play Console увімкніть **Play App Signing** — тоді це лише «ключ завантаження», і його можна відновити через підтримку.

## 3. Пакет для Play

```
./gradlew bundleRelease
```
Результат: `app/build/outputs/bundle/release/app-release.aab`. Для кожного нового завантаження збільшуйте
`versionCode` в `app/build.gradle`.

## 4. Play Console

| Розділ | Що вказати |
|---|---|
| Створити застосунок | Застосунок · Безкоштовний · мова за замовчуванням English (uk, ru додати як переклади) |
| Політика конфіденційності | URL публічної сторінки з `store/PRIVACY_POLICY.md` (наприклад, GitHub Pages) |
| Безпека даних | Дані не збираються і не передаються; шифрування/видалення — не застосовується |
| Реклама | Немає |
| Доступ до застосунку | Усі функції доступні без входу |
| Цільова аудиторія | 13+ (не «для дітей») |
| Рейтинг вмісту | Анкета → усі відповіді «Ні» → Everyone |
| Дозволи | Жодних; `QUERY_ALL_PACKAGES` не використовується (достатньо `<queries>`) |
| Графіка | `store/play-icon-512.png`, `store/play-feature-graphic-1024x500.png`, 2–8 скриншотів телефона (зробіть самі з Класики, Огляду, Фокуса, Вільного, Studio) |
| Тексти | `store/STORE_LISTING.md` |

Нові особисті акаунти розробників зазвичай мають спершу пройти **закрите тестування** (кілька тестувальників
протягом ~14 днів) перед виходом у продакшн — актуальні умови дивіться в Play Console → Dashboard.

## 5. Перед відправкою — чек-лист

- [ ] Перевірено на ≥2 пристроях (бажано Android 9–10 та 14–16) і в портреті/ландшафті
- [ ] Перший запуск: з’являється пропозиція зробити KAI головним екраном
- [ ] Список застосунків не порожній (Android 11+), нові/видалені застосунки з’являються самі
- [ ] «Назад» і жест «Назад» не закривають лаунчер
- [ ] Приховати → ⋯ → Приховані застосунки → повернути
- [ ] Тема Studio: Застосувати / Відкотити / Зберегти як тему
- [ ] Назва: див. примітку про торгову марку в `store/STORE_LISTING.md`
